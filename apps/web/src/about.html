About ISAT

ISAT (Insulin Sensitivity Analysis Tool) calculates surrogate indices of insulin sensitivity and resistance from fasting, oral glucose tolerance test (OGTT), lipid, anthropometric and tracer/DXA measurements. It is open source and runs entirely in the web browser.

Scientific scope

  • The indices are surrogate measures derived from routine measurements. They are not direct measurements of insulin sensitivity (such as the hyperinsulinaemic-euglycaemic clamp) and are not a diagnosis.
  • ISAT does not apply universal cut-offs or classify results. Interpretation depends on the population, protocol and assay.
  • Every formula, reference and verification level is listed on the Methods page, which is generated from the same method files the calculation engine uses.

Privacy

All calculations run locally in your browser. Data you enter or upload are not sent to any server; the site blocks every outgoing request except one: an anonymous visit counter (GoatCounter, no cookies). It records only which page was opened and that a file was uploaded or a calculation was run, with the file size as a rough band (e.g. 101–1,000 rows), never any value. Nothing is stored after you close the page.

Relationship to InsuSensCalc

ISAT is the successor to the R package InsuSensCalc. It accepts the same input column names. A small number of indices were deliberately corrected to their published definitions; each difference is documented on the Methods page.

How to cite

If you use ISAT, please cite the study for which the underlying index set was assembled:

Suleman S, Madsen AL, Ängquist LH, Schubert M, Linneberg A, Loos RJF, Hansen T, Grarup N. Genetic Underpinnings of Fasting and Oral Glucose-stimulated Based Insulin Sensitivity Indices. J Clin Endocrinol Metab. 2024;109(11):2754-2763. doi: 10.1210/clinem/dgae275. PMID: 38635292.

Please also cite the original publication of each index you report; these are listed with every result and on the Methods page. Please state the ISAT version (shown at the bottom of every page and in every results file).
