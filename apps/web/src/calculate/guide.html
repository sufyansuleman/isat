How to use this page

One person: Enter values

  1. Choose the units your lab reports (glucose, insulin, lipids).
  2. Fill in what you have. Fasting glucose and insulin are enough for the fasting indices; add OGTT time points, lipids or body measures for more.
  3. The panel Available calculations shows which indices can be calculated and what is missing for the others.
  4. Press Calculate. Each result shows the value, what a higher value means, the formula, the reference and the limitations.
  5. Use Download results CSV to save. Load example fills in a sample person.

Many people: Upload file

  1. Prepare a CSV file with one row per person (comma, semicolon or tab separated; decimal point, not comma). Download a template.
  2. Upload it, then choose the units used in the file. All rows must use the same units.
  3. Check the column list and the problem report, then press Calculate.
  4. Download the results CSV (one row per person) and the settings file (version, units and options used, for reproducibility). Click any person to see their full results.

Limit: 100,000 rows or 25 MB per file.

Column names

ColumnMeaning
participant_id (or id)Identifier, kept exactly as written
G0, G30, G60, G90, G120Glucose at that minute of the OGTT (0 = fasting)
I0, I30, I60, I90, I120Insulin at that minute (0 = fasting)
TG, HDL_c, FFAFasting triglycerides, HDL cholesterol, free fatty acids
age, sexYears; sex as 1 = male, 2 = female (or m/f, male/female)
weight, bmi, waistkg, kg/m², cm
fat_mass, rate_glycerol, rate_palmitateOptional: DXA fat mass (kg) and tracer rates

Only include the columns you have. Leave a cell empty when a value is missing; never enter 0 for missing. Other columns are ignored.

Good to know

  • Your data stay in this browser; nothing is uploaded.
  • Results are surrogate indices of insulin sensitivity, not direct measurements and not a diagnosis.
  • Insulin conversion uses 6.0 pmol/L per µU/mL by default; change it under Conversion factors if your lab uses another value.
  • Column names match the R package InsuSensCalc, so existing files can be uploaded directly.
