How to use this page

Many people: Upload file

  1. Prepare a CSV file with one row per person (comma, semicolon or tab separated; decimal point, not comma). Download an example file (10 participants; glucose, lipids and FFA in mmol/L, insulin in pmol/L; it includes people with a full OGTT, a 3-point OGTT, a missing 90-min sample and fasting values only).
  2. Upload it, then choose the units used in the file. All rows must use the same units. ISAT warns when the values in a column do not fit the chosen unit (for example glucose around 95 with mmol/L selected).
  3. Check the column list and the problem report, then press Calculate.
  4. Download the results CSV (one row per person) and the settings file (version, units and options used, for reproducibility). Click any person to see their full results.

Limit: 100,000 rows or 25 MB per file.

One person: Enter values

  1. Choose the units your lab reports (glucose, insulin, lipids).
  2. Fill in what you have. The row 0 min (fasting) is the sample taken before the glucose drink; fasting glucose and insulin alone are enough for the fasting indices. The other rows are minutes after a 75 g oral glucose drink (OGTT); add them, lipids or body measures for more indices.
  3. Grey values in empty boxes (e.g. 5.0) are examples for a typical healthy adult. They are only a guide and are never used unless you type them in.
  4. The line showing how many indices can be calculated updates as you type; Show which and why lists what is missing for the others.
  5. Press Calculate. Each result shows the value, what a higher value means, the formula, the population the index was derived in, the reference and the limitations.
  6. Use Download results CSV to save. Load example fills in a sample person.

Only fasting data? Include G0 and I0 and leave out the OGTT columns; the fasting indices (e.g. HOMA-IR, QUICKI) are still calculated. Only include the columns you have. Leave a cell empty when a value is missing; never enter 0 for missing. Other columns are ignored.

Good to know

  • Your data stay in this browser; nothing is uploaded.
  • Results are surrogate indices of insulin sensitivity, not direct measurements and not a diagnosis.
  • Each index was developed in one population (shown as Derived in) and may behave differently in others. Compare values within your own study rather than against cut-offs from elsewhere.
  • Insulin conversion uses 6.0 pmol/L per µU/mL by default; change it under Conversion factors if your lab uses another value.
  • Column names match the R package InsuSensCalc, so existing files can be uploaded directly.
